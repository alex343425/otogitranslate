上述倍率句型適用所有數值及 `{0}` 等參數，刪去倍率後多餘的「變為」，保留條件、對象、倍率與括號中的自身倍率。其他確有狀態變化意義的「變為」不受影響。

武器用語包含「武器種類『本』」、「本角色」、武器列表中的「本」與「本之刻印」。只按武器語意替換；「秘書」、「圖書室」、狀態名「書聖」、「書神」、「書記天使」、「聖翠書」及引用的技能名保留原有寫法。

- 「敵的防禦力／攻擊目標的防禦力一時的於 {0}% 減少並攻擊」統一為「無視敵方防禦力 {0}% 並發動攻擊」。百分比前後各留一個半形空格，百分號使用 `%`；保留原有參數編號或實際數值。
- 減益轉移的括號說明「一時的於攻擊目標狀態異常抗性{3}降低」改為「轉移時暫時降低目標狀態異常抗性{3}」。適用所有參數編號；保留括號外的機率、次數及增益吸取等其他效果。例如「低機率減益轉移(轉移時暫時降低目標狀態異常抗性{3})」。

- 「理不尽に敵の防御力を一時的に50%減少させて踏みつける」固定為「無視敵方防禦力50%並發動攻擊」。這兩項特殊句型依使用者指定，50% 前後不留空格。
